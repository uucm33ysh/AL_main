# EndNote 참고문헌 산출물

[verified_Park_Zhao.ris](verified_Park_Zhao.ris)는 사용자 업로드 원문 PDF에서 확인한2개 레코드입니다. 원래AL.enl을 수정한 파일이 아닙니다.

- Park JS et al. COLRAR. Ann Surg2023;278(1):31–38. DOI10.1097/SLA.0000000000005788. 저자10명.
- Zhao S et al. TDT trial. JAMA Surg2021;156(12):1151–1158. DOI10.1001/jamasurg.2021.4568. 저자18명.

## 사용 순서
1. EndNote library백업.
2. File → Import → File에서 RIS파일 선택, Import Option: Reference Manager(RIS).
3. 가져온 저자/저널/연도/권호/페이지/DOI 확인. 불완전한 기존레코드와 중복되지 않게 정리한 뒤 사용.
4. Word 복사본에서 EndNote Insert Citation으로 삽입. 출력스타일을 맞추고 자동bibliography와 기존 일반텍스트목록이 중복되지 않는지 확인.

[reviews](reviews/)의 날짜별 점검과 원문근거를 함께 참고하세요. 현재 EndNote native 앱에서의 import/Word갱신은 직접 검증하지 않았습니다. PDF 전체는 포함하지 않습니다. 사용자 요청으로 별도 보관한 최신 라이브러리는 [2026-11-18 보관본](../manuscript_versions/2026-11-18/AL_new.enlx)을 사용하세요.
